# Trabalhos de Sistemas Operacionais (SO)

Este repositório contém os trabalhos práticos desenvolvidos para a disciplina de Sistemas Operacionais. 
Os trabalhos exploram conceitos fundamentais da disciplina, como concorrência, sincronização de processos e programação paralela em C.

## Estrutura do Repositório

- **[Trabalho Prático 1 (TP1)](./tp1)**: Focado em problemas clássicos de sincronização e concorrência (Leitores e Escritores, Produtores e Consumidores). Demonstra problemas de condição de corrida e como controlá-los usando primitivas de sincronização.
- **[Trabalho Prático 2 (TP2)](./tp2)**: Focado em paralelismo e concorrência aplicados a problemas práticos, como simulação de um servidor web e operações matemáticas intensivas (produto escalar e multiplicação matricial) visando análise de desempenho.

Cada diretório contém seu próprio arquivo README com mais detalhes sobre as implementações e como executá-las.
